Consistency is what turns a visual system into a brand. A logo used correctly once means nothing. A logo used correctly across every touchpoint, every time, by every team member and every external partner — that is what builds recognition, trust, and equity. This page is a quick-reference guide for the most common brand application scenarios you will encounter. Return to it often, share it with collaborators, and use it as the first checkpoint before any branded material goes out the door.

## Logo Dos & Don'ts

<CardGroup cols={2}>
  <Card title="Logo: Do" icon="check" href="/brand/logo">
    - Use the official Alchemetryx logo files downloaded from the brand asset library
    - Maintain the minimum clear space of 1× the logo height on all sides at all times
    - Use the white logo version on dark backgrounds (Deep Navy, Teal, or photographic backgrounds)
    - Use the full-colour version on Off-White, white, or light neutral backgrounds
    - Scale the logo proportionally, holding the corner handle while resizing
  </Card>
  <Card title="Logo: Don't" icon="xmark" href="/brand/logo">
    - Never stretch, squash, or distort the logo in any dimension
    - Never recreate or redraw the logo in any design tool — always use the provided files
    - Never place the logo on a busy, high-contrast photographic background without a solid colour container
    - Never add drop shadows, outlines, glows, or any visual effects to the logo
    - Never use an outdated version of the logo — check the asset library before every new project
  </Card>
</CardGroup>

## Colour Dos & Don'ts

<CardGroup cols={2}>
  <Card title="Colour: Do" icon="check" href="/brand/color-palette">
    - Use Orange (`#ef7025`) for primary CTAs, buttons, accent bars, and key moments of emphasis
    - Use Teal (`#4fa1ab`) for secondary actions, data visualisations, and supporting typographic accents
    - Use Peach (`#eec9bc`) for warmth, background tints on feature sections, and secondary graphic elements
    - Use Deep Navy (`#1a1f36`) for footers, cover pages, and authoritative dark-background moments
    - Use Off-White (`#f9f5f0`) as the default light background across web and print
  </Card>
  <Card title="Colour: Don't" icon="xmark" href="/brand/color-palette">
    - Never use Orange as a background colour for large areas of body text — contrast and legibility suffer
    - Never introduce colours outside the brand palette without explicit brand approval
    - Never use pure black (`#000000`) as a text colour — use Dark Charcoal (`#2d2d2d`) instead
    - Never place Orange text on a Teal background or Teal text on an Orange background — both combinations fail accessibility contrast standards
    - Never use multiple accent colours in the same design element — pick one and commit to it
  </Card>
</CardGroup>

## Typography Dos & Don'ts

<CardGroup cols={2}>
  <Card title="Typography: Do" icon="check" href="/brand/typography">
    - Use Inter for all UI text, body copy, labels, captions, and navigation elements
    - Use Playfair Display for pull quotes, editorial headings, and moments where warmth and personality are the priority
    - Maintain a clear typographic hierarchy — one H1 per page, H2 for major sections, H3 for subsections
    - Left-align body text in all layouts — never justify type in digital or print contexts
    - Use Inter Semi-Bold for emphasis rather than adding underlines or italics to body copy
  </Card>
  <Card title="Typography: Don't" icon="xmark" href="/brand/typography">
    - Never use fonts outside the approved brand typefaces — no system fonts, no Google Fonts substitutions, no decorative display fonts
    - Never set body text smaller than 14px on screen or 9pt in print
    - Never use all-caps for more than a short label or button text — extended all-caps body copy is difficult to read
    - Never mix Inter and Playfair Display in the same sentence or paragraph — use each typeface for its designated role
    - Never rely on type colour alone to convey meaning — always pair colour with size, weight, or position
  </Card>
</CardGroup>

## Photography Dos & Don'ts

<CardGroup cols={2}>
  <Card title="Photography: Do" icon="check" href="/brand/imagery-iconography">
    - Use photography that features real, authentic people in purposeful, work-oriented situations
    - Apply warm colour grading consistent with the brand palette — lifted shadows, slightly warm white balance
    - Choose images where the subject has clear intentionality — a person mid-thought, mid-analysis, mid-conversation
    - Ensure photographic backgrounds are clean enough to overlay text at sufficient contrast
    - Commission bespoke photography for key brand moments — website hero, social profile, event collateral
  </Card>
  <Card title="Photography: Don't" icon="xmark" href="/brand/imagery-iconography">
    - Never use generic stock photography — no handshake photos, no people-pointing-at-whiteboards, no staged boardroom scenes
    - Never use heavily filtered, oversaturated, or artificially brightened photographs
    - Never crop a portrait image so that the subject's eyes are cut off or obscured
    - Never use photography with busy, cluttered backgrounds on feature sections where brand clarity matters
    - Never mix photographic styles within a single designed artefact — choose documentary or studio, not both
  </Card>
</CardGroup>

## Tone of Voice Dos & Don'ts

<CardGroup cols={2}>
  <Card title="Tone: Do" icon="check" href="/brand/tone-of-voice">
    - Write in second person ("you") to keep the focus on the client's transformation, not Alchemetryx's credentials
    - Use active voice — say "we build strategies" not "strategies are built by us"
    - Be specific: use numbers, outcomes, and tangible examples wherever possible
    - Match the level of warmth to the channel — slightly more relaxed on Instagram, more precise in proposals
    - Edit ruthlessly — every sentence should earn its place
  </Card>
  <Card title="Tone: Don't" icon="xmark" href="/brand/tone-of-voice">
    - Never use hollow corporate jargon — avoid "synergise," "leverage," "best-in-class," and "thought leader"
    - Never hedge so much that the point disappears — own your perspective
    - Never write in third person about Alchemetryx in client-facing communications — it creates distance
    - Never use exclamation marks in professional documents, proposals, or reports
    - Never sacrifice clarity for cleverness — if a sentence requires two reads, rewrite it
  </Card>
</CardGroup>

## Quick-Reference Checklist

Use these checklists before publishing or distributing any branded material. If you cannot tick every item, do not release the asset.

<Accordion title="Website Checklist">
  Before publishing any new web page or updating an existing one, confirm:

  - [ ] All backgrounds use Off-White (`#f9f5f0`), white (`#ffffff`), or Deep Navy (`#1a1f36`) — no off-brand colours introduced
  - [ ] Primary CTA buttons are Orange fill with white text; secondary buttons are Teal outline with Teal text
  - [ ] Minimum section padding of 48px applied on all breakpoints — check mobile view
  - [ ] All images have descriptive alt text and meet the photography guidelines
  - [ ] The Alchemetryx logo appears correctly sized with full clear space respected in the header
  - [ ] Page meta title, description, and OG image have been set using approved brand copy
</Accordion>

<Accordion title="Social Media Checklist">
  Before posting any content to a social channel, confirm:

  - [ ] The post uses the correct image dimensions for the platform and format
  - [ ] Any graphic uses only brand colours, brand fonts, and approved iconography
  - [ ] The caption is written in the appropriate tone for that channel (see Social Media guidelines)
  - [ ] No generic stock photography has been used — images meet the Alchemetryx imagery standards
  - [ ] The Alchemetryx handle or watermark is included on branded graphic tiles where appropriate
</Accordion>

<Accordion title="Email Checklist">
  Before sending any branded email, confirm:

  - [ ] The email header uses an Orange or Teal bar with the Alchemetryx wordmark in white
  - [ ] Body text is Inter 16px on a white background — no custom fonts loaded via web font
  - [ ] There is exactly one primary CTA button per email, using the Orange fill style
  - [ ] The footer is Deep Navy with white text, an unsubscribe link, and the physical address
  - [ ] A plain-text version of the email has been created and tested in a plain-text client
</Accordion>

<Accordion title="Presentations Checklist">
  Before sharing or presenting any Alchemetryx deck, confirm:

  - [ ] The official Alchemetryx slide template has been used — not a client template or blank canvas
  - [ ] The mission statement slide appears as slide 2, immediately after the title slide
  - [ ] All data visualisations use Teal as the primary series colour — not Orange
  - [ ] The final slide is a transformation CTA slide on Deep Navy with contact details
  - [ ] All fonts are embedded or the file has been exported as PDF before sharing externally
</Accordion>

<Accordion title="Print Checklist">
  Before sending any file to print production, confirm:

  - [ ] The file is in CMYK colour mode using the approved CMYK values from the print guidelines
  - [ ] All images are at least 300 DPI at final print size
  - [ ] The file includes 3mm bleed on all sides with crop marks and colour bars
  - [ ] All fonts are embedded or outlined — no live font data in the exported file
  - [ ] A physical proof has been requested and approved before committing to the full print run
</Accordion>

<Tip>
  When in doubt, simplify. The Alchemetryx brand is strongest when it has room to breathe. Less clutter, more impact. A single well-placed Orange headline on an Off-White background will always outperform a page crowded with competing colours, fonts, and messages. Trust the system — it was built to do the heavy lifting.
</Tip>
